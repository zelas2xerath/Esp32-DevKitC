## 🎯 系统概述

ESP32传感器管理系统是一个基于FreeRTOS的多传感器数据采集、处理和管理平台。系统经过九个阶段的优化，具备完整的传感器管理、数据滤波、智能分析和远程监控能力。

### 核心特性

- **多传感器支持**: SMS、WDS、LIS、ECS、CAS五种传感器类型
- **实时数据处理**: 基于FreeRTOS的多任务并发处理
- **智能数据滤波**: 移动平均、中位数、异常值检测
- **智能光照管理**: 光照等级分析、趋势预测、模式自动切换
- **远程监控**: MQTT协议支持，实时数据传输
- **高可靠性**: 完整的错误处理和恢复机制

### 应用场景

- **智能农业**: 温室环境监控、作物生长管理
- **智能家居**: 环境自动调节、节能控制
- **工业监控**: 生产环境监测、设备状态管理
- **科研实验**: 精密环境控制、数据记录分析

## 🔧 核心组件详细设计

### 1. RTOS任务架构

#### 任务优先级设计
```cpp
// 任务优先级定义（数值越大优先级越高）
#define TASK_PRIORITY_SYSTEM    5    // 系统管理任务（最高优先级）
#define TASK_PRIORITY_SENSOR    4    // 传感器数据采集任务
#define TASK_PRIORITY_NETWORK   3    // 网络通信任务
#define TASK_PRIORITY_DISPLAY   2    // 显示更新任务
#define TASK_PRIORITY_IDLE      1    // 空闲任务（最低优先级）
```

#### 任务间通信机制
```cpp
// 队列设计
QueueHandle_t xSensorDataQueue;     // 传感器数据队列（32个消息）
QueueHandle_t xNetworkQueue;        // 网络数据队列（16个消息）
QueueHandle_t xSystemEventQueue;    // 系统事件队列（8个消息）

// 信号量设计
SemaphoreHandle_t xSensorMutex;     // 传感器访问互斥锁
SemaphoreHandle_t xNetworkMutex;    // 网络访问互斥锁
SemaphoreHandle_t xDisplayMutex;    // 显示访问互斥锁
```

#### 任务调度策略
- **SensorTask**: 1000ms周期，负责传感器数据采集和初步处理
- **NetworkTask**: 事件驱动，处理MQTT通信和数据上传
- **SystemTask**: 5000ms周期，系统状态监控和维护
- **DisplayTask**: 2000ms周期，显示界面更新

### 2. 传感器管理架构

#### 统一传感器接口设计
```cpp
// 所有传感器类都遵循统一的设计模式
class SensorBase {
public:
    virtual bool begin() = 0;                    // 初始化
    virtual ErrorCode getLastErrorCode() = 0;    // 获取错误码
    virtual String getLastErrorMessage() = 0;    // 获取错误信息
    virtual unsigned long getReadCount() = 0;    // 获取读取次数
    static bool isDataValid(...) = 0;           // 静态数据验证方法
};
```

#### 传感器类型和特性
| 传感器 | 数据类型 | 更新频率 | 精度 | 应用场景 |
|--------|----------|----------|------|----------|
| SMS | int (0-4095) | 1Hz | 12位ADC | 土壤湿度监测 |
| WDS | double (0-200cm) | 1Hz | ±1cm | 水位监测 |
| LIS | float (0-65535 lux) | 1Hz | ±5% | 光照监测 |
| ECS | float (温湿压) | 1Hz | ±0.5°C/±3%/±1hPa | 环境监测 |
| CAS | 多参数结构体 | 1Hz | 综合精度 | 土壤综合分析 |

### 3. 数据滤波架构

#### 滤波器层次结构
```cpp
DataFilterManager
├── NumericDataFilter<int>      (SMS滤波器)
├── NumericDataFilter<double>   (WDS滤波器)
├── NumericDataFilter<float>    (LIS滤波器)
├── EnvironmentDataFilter       (ECS滤波器)
│   ├── 温度滤波器
│   ├── 湿度滤波器
│   └── 气压滤波器
└── SoilDataFilter             (CAS滤波器)
    ├── 土壤温度滤波器
    ├── 土壤湿度滤波器
    ├── pH滤波器
    ├── EC滤波器
    └── 营养元素滤波器
```

#### 滤波算法组合
1. **移动平均滤波器**: 平滑数据波动，减少噪声
2. **中位数滤波器**: 去除突发异常值，保持数据连续性
3. **统计异常值检测**: 基于3σ原则和变化率检测异常数据

#### 滤波性能指标
- **处理延迟**: < 10μs (单个传感器)
- **内存占用**: < 2KB (所有滤波器)
- **异常值检测率**: > 95%
- **数据平滑度**: 显著改善

```
│   └── DisplayTask: 4KB

├── 光照管理器: 2KB
└── 其他缓存: 8KB

总Flash使用: 91.7% (约3.67MB/4MB)
├── 应用程序代码: 2.8MB
├── RTOS内核: 0.5MB
├── 库文件: 0.3MB
└── 预留空间: 0.07MB
```

### 内存优化策略
1. **环形缓冲区**: 滤波器使用固定大小的环形缓冲区
2. **对象池**: 重用消息对象，减少动态分配
3. **栈优化**: 精确计算任务栈大小，避免浪费
4. **数据压缩**: 网络传输时压缩JSON数据

## 🛡️ 安全性设计

### 数据安全
- **数据加密**: MQTT传输支持TLS加密
- **访问控制**: 基于用户名密码的访问控制
- **数据完整性**: CRC校验确保数据完整性
- **隐私保护**: 敏感数据本地处理，不上传云端

### 系统安全
- **看门狗机制**: 硬件和软件双重看门狗保护
- **故障隔离**: 单个传感器故障不影响整体系统
- **安全启动**: 固件签名验证，防止恶意代码
- **OTA安全**: 加密的固件更新机制

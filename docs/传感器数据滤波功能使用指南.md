# 传感器数据滤波功能使用指南

## 📋 功能概述

传感器数据滤波功能是ESP32传感器管理系统的重要组成部分，提供异常值检测和数据质量控制，确保传感器数据的可靠性和稳定性。

### 🎯 主要功能

1. **移动平均滤波器** - 平滑数据波动，减少噪声影响
2. **中位数滤波器** - 去除突发异常值，保持数据连续性
3. **统计异常值检测** - 基于3σ原则和变化率检测异常数据
4. **多传感器支持** - 支持SMS、WDS、LIS、ECS、CAS所有传感器类型
5. **实时处理** - 在RTOS任务中实时处理，不影响系统性能

### 🏗️ 系统架构

```
传感器硬件层 → 数据滤波层 → 业务逻辑层 → 数据输出
     ↓              ↓              ↓           ↓
   SMS/WDS/      DataFilter    SensorTask   MQTT/Display
   LIS/ECS/        Manager                    
   CAS类                                      
```

## 🔧 使用方法

### 1. 启用/禁用滤波功能

在 `DataFilterConfig.h` 中修改配置：

```cpp
// 完全禁用滤波功能
#define ENABLE_DATA_FILTERING           false

// 只启用移动平均滤波
#define ENABLE_DATA_FILTERING           true
#define ENABLE_MOVING_AVERAGE_FILTER    true
#define ENABLE_MEDIAN_FILTER            false
#define ENABLE_OUTLIER_DETECTION        false
```

### 2. 调整滤波参数

根据应用场景调整参数：

```cpp
// 对于变化缓慢的传感器（如土壤温度），使用较大的窗口和权重
#define SENSOR_FILTER_WINDOW_SIZE       20
#define SENSOR_MOVING_AVERAGE_WEIGHT    0.9f

// 对于变化较快的传感器（如光照），使用较小的窗口和权重
#define SENSOR_FILTER_WINDOW_SIZE       5
#define SENSOR_MOVING_AVERAGE_WEIGHT    0.6f
```

### 3. 监控滤波效果

启用调试日志查看滤波效果：

```cpp
#define ENABLE_FILTER_DEBUG_LOG         true
#define ENABLE_FILTER_PERFORMANCE_LOG   true
```

日志输出示例：
```
[TRACE] SMS滤波: 原始值=2150, 滤波值=2145
[TRACE] ECS滤波: T=25.3->25.1°C, H=65.2->64.8%, P=1013.2->1013.0hPa
[TRACE] CAS滤波: T=22.1->22.0°C, M=45.3->45.1%, pH=6.85->6.84, EC=1250->1245 μS/cm
```

## 📊 滤波算法详解

### 1. 移动平均滤波器

**原理**：计算窗口内所有数据的平均值，平滑数据波动。

**适用场景**：
- 传感器噪声较大
- 数据变化相对平缓
- 需要平滑的数据曲线

**配置建议**：
- 窗口大小：3-50个样本
- 权重：0.1-1.0（越大越平滑）

### 2. 中位数滤波器

**原理**：取窗口内数据的中位数，有效去除突发异常值。

**适用场景**：
- 存在突发干扰
- 需要保持数据的边缘特征
- 异常值呈脉冲状分布

**配置建议**：
- 窗口大小：3-15个样本（奇数更佳）
- 适合处理椒盐噪声

### 3. 统计异常值检测

**原理**：基于3σ原则和变化率检测异常数据。

**检测条件**：
1. 数据超出均值±σ倍数范围
2. 变化率超过设定阈值
3. 数据超出传感器有效范围

**配置建议**：
- σ倍数：2.0-3.0（越小越敏感）
- 变化率根据传感器特性设定

## 🚀 性能优化

### 内存使用

每个滤波器的内存使用：
```cpp
// 单个数值滤波器内存使用
Memory = WindowSize × DataTypeSize + FixedOverhead
// 例：SMS滤波器 = 10 × 4字节 + 约50字节 = 90字节

// 环境传感器滤波器（3个参数）
ECS Memory = 3 × (12+10+15) × 4字节 + 约150字节 = 594字节

// 土壤综合传感器滤波器（8个参数）
CAS Memory = 8 × 平均窗口大小 × 数据类型大小 + 约400字节
```

### 计算复杂度

- **移动平均**：O(1) - 增量计算
- **中位数**：O(n log n) - 排序算法
- **异常值检测**：O(n) - 统计计算

### 实时性保证

- 滤波处理在传感器读取后立即执行
- 不阻塞RTOS任务调度
- 超时机制防止长时间计算

## 🔍 故障排除

### 常见问题

1. **滤波效果不明显**
   - 检查是否启用了滤波功能
   - 增大滤波窗口大小
   - 调整移动平均权重

2. **响应速度太慢**
   - 减小滤波窗口大小
   - 降低移动平均权重
   - 禁用中位数滤波

3. **异常值检测过于敏感**
   - 增大异常值阈值
   - 增大变化率阈值
   - 增加统计样本数要求

4. **内存不足**
   - 减小滤波窗口大小
   - 禁用不必要的滤波器
   - 检查MAX_FILTER_WINDOW_SIZE设置

## 📈 最佳实践

### 1. 参数调优建议

- **土壤传感器**：使用较大窗口（15-25），高权重（0.8-0.9）
- **环境传感器**：使用中等窗口（10-15），中等权重（0.7-0.8）
- **光照传感器**：使用较小窗口（5-10），低权重（0.6-0.7）
- **水位传感器**：使用中等窗口（8-12），中等权重（0.7-0.8）

### 2. 应用场景优化

- **室内环境**：可以使用较强的滤波（大窗口、高权重）
- **室外环境**：需要平衡滤波强度和响应速度
- **工业环境**：重点关注异常值检测和噪声滤除

### 3. 系统集成建议

- 在系统启动时初始化滤波器
- 定期检查滤波器状态和统计信息
- 根据实际使用情况调整参数
- 保留原始数据用于故障分析

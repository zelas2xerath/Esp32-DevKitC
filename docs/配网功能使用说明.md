# ESP32 土壤监测系统 - 配网功能使用说明

## 功能概述

ESP32土壤监测系统新增了智能配网功能，用户可以通过Web界面轻松配置WiFi网络和服务器参数，无需修改代码或重新编译程序。

## 主要特性

### 1. 自动配网检测
- **首次启动检测**：设备首次启动时自动检测是否已配置网络
- **配置失效检测**：当保存的配置无效时自动进入配网模式
- **智能切换**：配网完成后自动重启并连接到指定网络

### 2. Web配网界面
- **美观的界面**：现代化的Web界面，支持手机和电脑访问
- **表单验证**：实时验证输入参数的有效性
- **状态反馈**：实时显示配置保存状态和结果

### 3. 配置持久化
- **NVS存储**：配置信息保存在ESP32的非易失性存储中
- **配置验证**：保存前验证配置的完整性和有效性
- **配置重置**：支持重置配置，恢复到出厂状态

## 配网流程

### 1. 设备启动
```
设备启动 → 检查配置 → 配置有效 → 正常连接
                ↓
            配置无效/缺失 → 启动配网模式
```

### 2. 配网模式
```
启动AP → 用户连接WiFi → 访问Web界面 → 填写配置 → 保存配置 → 重启设备
```

### 3. 配置验证
```
接收配置 → 验证参数 → 保存到NVS → 重启系统 → 连接指定网络
```

## 使用方法

### 首次配网

1. **设备启动**
   - 给ESP32上电
   - 观察OLED显示："网络未配置，启动配网模式"

2. **连接配网WiFi**
   - 用手机或电脑连接WiFi网络：`ESP32_CME`
   - WiFi密码：`12345678`

3. **访问配网界面**
   - 打开浏览器，访问：`http://192.168.4.1`
   - 会自动跳转到配网页面

4. **填写配置信息**
   - **WiFi名称**：您的WiFi网络名称
   - **WiFi密码**：您的WiFi网络密码
   - **服务器IP**：数据服务器的IP地址（默认：192.168.1.100）
   - **服务器端口**：数据服务器的端口号（默认：7289）
   - **NTP服务器**：时间同步服务器（默认：ntp1.aliyun.com）

5. **保存配置**
   - 点击"保存配置"按钮
   - 等待配置保存成功提示
   - 设备会自动重启并连接到指定网络

### 重新配网

如果需要修改网络配置，可以通过以下方式：

1. **重置配置**
   ```cpp
   // 在代码中调用
   configManager->resetConfig();
   ```

2. **手动触发配网**
   - 重启设备
   - 如果配置无效，会自动进入配网模式

## 技术实现

### 核心组件

#### 1. ConfigManager类
```cpp
class ConfigManager {
    // 配置管理
    bool begin();                    // 初始化配置管理器
    bool startConfigMode();          // 启动配网模式
    bool saveConfig(const NetworkConfig& config);  // 保存配置
    NetworkConfig loadConfig();      // 加载配置
    void resetConfig();              // 重置配置
    
    // Web服务器
    void handleWebServer();          // 处理Web请求
    void handleSaveConfig();         // 处理配置保存
};
```

#### 2. NetworkConfig结构体
```cpp
struct NetworkConfig {
    char wifiSSID[32];              // WiFi名称
    char wifiPassword[64];           // WiFi密码
    char serverIP[16];               // 服务器IP
    uint16_t serverPort;             // 服务器端口
    char ntpServer[32];              // NTP服务器
    long gmtOffset;                  // 时区偏移
    int daylightOffset;              // 夏令时偏移
};
```

### 存储机制

#### NVS存储结构
```
network_cfg/
├── wifi_ssid          // WiFi名称
├── wifi_pass          // WiFi密码
├── server_ip          // 服务器IP
├── server_port        // 服务器端口
├── ntp_server         // NTP服务器
├── gmt_offset         // 时区偏移
├── daylight_offset    // 夏令时偏移
└── configured         // 配置状态标志
```

### Web服务器

#### 路由配置
- `GET /` - 配网主页面
- `POST /save` - 保存配置接口
- `*` - 重定向到主页

#### API接口
```json
POST /save
Content-Type: application/json

{
    "ssid": "WiFi名称",
    "password": "WiFi密码",
    "server_ip": "192.168.1.100",
    "server_port": 7289,
    "ntp_server": "ntp1.aliyun.com"
}

Response:
{
    "success": true,
    "message": "配置保存成功"
}
```

## 配置参数说明

### WiFi配置
- **SSID**：WiFi网络名称，最大32字符
- **密码**：WiFi网络密码，最大64字符

### 服务器配置
- **IP地址**：数据服务器的IP地址，支持IPv4格式
- **端口**：服务器端口号，范围1-65535

### 时间配置
- **NTP服务器**：网络时间协议服务器地址
- **时区偏移**：相对于GMT的时区偏移（秒）
- **夏令时偏移**：夏令时偏移（秒）

## 安全考虑

### 1. 配网安全
- 配网WiFi有固定密码，仅用于配置
- 配网完成后自动关闭AP模式
- 配置信息加密存储在NVS中

### 2. 数据验证
- 所有输入参数都进行格式验证
- 防止恶意数据导致系统异常
- 配置保存前进行完整性检查

### 3. 错误处理
- 配网超时自动退出
- 配置失败时提供错误信息
- 网络异常时自动重试

## 故障排除

### 常见问题

1. **无法连接配网WiFi**
   - 检查WiFi名称：`ESP32_SoilMonitor`
   - 检查密码：`12345678`
   - 确认设备已进入配网模式

2. **配网页面无法访问**
   - 确认已连接到配网WiFi
   - 尝试访问：`http://192.168.4.1`
   - 检查浏览器是否支持JavaScript

3. **配置保存失败**
   - 检查所有必填字段是否已填写
   - 确认服务器IP格式正确
   - 检查端口号是否在有效范围内

4. **配网后无法连接网络**
   - 检查WiFi名称和密码是否正确
   - 确认WiFi信号强度
   - 检查服务器是否可达

### 调试方法

1. **查看串口日志**
   ```
   [提示] 网络未配置，启动配网模式
   [提示] 配网AP已启动: ESP32_SoilMonitor
   [提示] 配网Web服务器启动成功
   [提示] 收到配置数据: {...}
   [提示] 配置保存成功
   ```

2. **观察OLED显示**
   - "网络未配置，启动配网模式"
   - "配网AP已启动，IP: 192.168.4.1"
   - "配置已保存，系统重启中..."

3. **网络诊断**
   - 使用ping命令测试服务器连通性
   - 检查防火墙设置
   - 确认网络配置正确

# 水位监测与警报系统说明

## 功能概述

水位监测与警报系统是ESP32土壤监测系统的一项新特性，用于实时监测水位变化并在异常情况下发出警报。该系统集成了以下功能：

1. **实时水位监测**：通过MSP20水深压力传感器实时监测水位变化
2. **多级警报机制**：根据水位高低设置不同级别的警报
3. **系统状态管理**：将水位状态集成到系统整体状态管理中
4. **紧急事件处理**：在检测到洪水风险时触发紧急事件
5. **远程通知**：将警报信息通过网络发送到服务器

## 水位等级定义

系统定义了以下水位等级：

- **干燥 (DRY)**：水位 < 1 cm
- **浅水 (SHALLOW)**：水位 1-10 cm
- **正常 (NORMAL)**：水位 10-50 cm
- **深水 (DEEP)**：水位 50-100 cm
- **很深 (VERY_DEEP)**：水位 100-200 cm
- **极深 (EXTREME_DEEP)**：水位 > 200 cm

## 警报触发条件

系统根据不同的水位等级触发不同级别的警报：

| 水位等级 | 系统状态 | 警报级别 | 显示信息 |
|---------|---------|---------|---------|
| DRY | NORMAL | 提示 | 水位过低 |
| SHALLOW | NORMAL | 无 | 无 |
| NORMAL | NORMAL | 无 | 无 |
| DEEP | WARNING | 警告 | 水位较高 |
| VERY_DEEP | WARNING | 警告 | 水位很高 |
| EXTREME_DEEP | ERROR | 错误 | 水位过高 |

当水位达到EXTREME_DEEP且检测到洪水状态时，系统会触发FloodingAlert事件，并将系统状态设置为CRITICAL。

## 使用方法

系统会自动监测水位并在必要时发出警报，无需手动干预。水位信息会定期上传到服务器，并在OLED显示屏上显示。

### 查看当前水位

可以通过以下方式查看当前水位信息：

1. **OLED显示**：系统会定期在OLED屏幕上显示水位信息
2. **串口监视器**：通过串口监视器可以查看水位日志信息
3. **远程监控**：通过服务器接收的数据可以远程监控水位变化

### 警报处理

当系统发出水位警报时，可以采取以下措施：

1. 检查水位传感器是否正常工作
2. 检查水源是否存在异常情况
3. 采取必要的措施调整水位
4. 如果是洪水警报，应立即采取防洪措施

## 技术实现

### 核心类和方法

- **WDS类**：水深传感器管理类，负责读取和处理水位数据
- **SystemManager::checkWaterLevelAlerts()**：检查水位并处理警报
- **SystemManager::updateSystemState()**：更新系统状态
- **SystemManager::processEvents()**：处理事件，包括FloodingAlert事件

### 事件处理

系统定义了FloodingAlert事件类型，当检测到洪水风险时会触发该事件。事件处理流程如下：

1. 水位传感器检测到极高水位
2. 系统调用checkWaterLevelAlerts()方法
3. 如果水位达到洪水级别，系统发送FloodingAlert事件
4. processEvents()方法处理该事件，设置系统为严重错误状态
5. 系统显示错误信息并发送远程通知

## 配置参数

水位监测系统的参数可以通过以下方式配置：

- **水位阈值**：可以在代码中修改WaterLevel枚举的定义来调整不同水位等级的阈值
- **检查间隔**：可以在SystemManager::uploadWaterData()方法中修改loop()调用的间隔参数

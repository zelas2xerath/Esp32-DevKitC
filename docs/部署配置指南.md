# ESP32传感器管理系统部署配置指南

## 📋 文档信息

- **项目名称**: ESP32智能传感器管理系统
- **版本**: v9.0.0
- **文档版本**: v1.0.0
- **创建日期**: 2025-07-21
- **适用对象**: 系统管理员、运维工程师、技术人员

## 🎯 部署概述

本指南提供ESP32传感器管理系统的完整部署流程，包括硬件连接、软件配置、系统调试和故障排除等内容。

### 系统要求

#### 硬件要求
- **主控板**: ESP32开发板（推荐ESP32-DevKitC）
- **内存**: 最小320KB RAM, 4MB Flash
- **传感器**: 支持SMS、WDS、LIS、ECS、CAS传感器
- **电源**: 5V/2A电源适配器
- **存储**: 可选SD卡模块用于数据存储

#### 软件要求
- **开发环境**: PlatformIO IDE 或 Arduino IDE
- **编译器**: ESP-IDF v4.4+
- **操作系统**: Windows 10+, macOS 10.15+, Ubuntu 18.04+
- **网络**: WiFi网络环境
- **MQTT服务器**: 可选的MQTT Broker

## 🔌 硬件连接图

### ESP32引脚分配表

| 功能 | 引脚 | 传感器类型 | 说明 |
|------|------|------------|------|
| ADC1_CH0 | GPIO36 | SMS | 土壤湿度传感器模拟输入 |
| GPIO4 | GPIO4 | SMS | 土壤湿度传感器电源控制 |
| GPIO5 | GPIO5 | WDS | 超声波传感器触发引脚 |
| GPIO18 | GPIO18 | WDS | 超声波传感器回声引脚 |
| SDA | GPIO21 | LIS/ECS | I2C数据线 |
| SCL | GPIO22 | LIS/ECS | I2C时钟线 |
| RX2 | GPIO16 | CAS | UART2接收引脚 |
| TX2 | GPIO17 | CAS | UART2发送引脚 |
| GPIO2 | GPIO2 | CAS | RS485方向控制引脚 |

### 传感器连接详情

#### SMS土壤湿度传感器
```

GND    ──── GND

DO     ──── 未连接
```

#### WDS超声波水位传感器
```
WDS传感器    ESP32
VCC    ──── 5V
GND    ──── GND
Trig   ──── GPIO5
Echo   ──── GPIO18
```

#### LIS光照传感器 (I2C)
```
LIS传感器    ESP32
VCC    ──── 3.3V
GND    ──── GND
SDA    ──── GPIO21
SCL    ──── GPIO22
ADDR   ──── GND (地址0x23)
```

#### ECS环境传感器 (I2C)
```
ECS传感器    ESP32
VCC    ──── 3.3V
GND    ──── GND
SDA    ──── GPIO21
SCL    ──── GPIO22
CSB    ──── 3.3V
SDO    ──── GND (地址0x76)
```

#### CAS土壤综合传感器 (RS485)
```
CAS传感器    ESP32
VCC    ──── 5V
GND    ──── GND
A+     ──── RS485模块A+
B-     ──── RS485模块B-

RS485模块    ESP32
VCC    ──── 3.3V
GND    ──── GND
RO     ──── GPIO16 (RX2)
DI     ──── GPIO17 (TX2)
DE     ──── GPIO2
RE     ──── GPIO2
```

## 💻 编译环境搭建

### 方法一：使用PlatformIO IDE（推荐）

#### 1. 安装Visual Studio Code
```bash
# 下载并安装VS Code
https://code.visualstudio.com/

# 安装PlatformIO扩展
在VS Code扩展市场搜索"PlatformIO IDE"并安装
```

#### 2. 克隆项目代码
```bash
git clone https://github.com/your-repo/esp32-sensor-management.git
cd esp32-sensor-management
```

#### 3. 配置platformio.ini
```ini
[env:esp32dev]
platform = espressif32
board = esp32dev
framework = arduino
monitor_speed = 115200
lib_deps = 
    bblanchon/ArduinoJson@^6.19.4
    knolleary/PubSubClient@^2.8
    adafruit/Adafruit Unified Sensor@^1.1.4
    adafruit/Adafruit BME280 Library@^2.2.2
    claws/BH1750@^1.1.4
    thijse/ArduinoLog@^1.1.1

build_flags = 
    -DCORE_DEBUG_LEVEL=3
    -DCONFIG_ARDUHAL_LOG_COLORS=1

upload_speed = 921600
monitor_filters = esp32_exception_decoder
```

#### 4. 编译和上传
```bash
# 编译项目
pio run

# 上传到ESP32
pio run --target upload

# 监控串口输出
pio device monitor
```

## 🐛 故障排除

### 常见问题及解决方案

#### 1. 编译错误
```bash
问题: 找不到库文件
解决: 检查platformio.ini中的lib_deps配置，确保所有依赖库已安装

问题: 内存不足
解决: 检查分区方案，使用"Default 4MB with spiffs"

问题: 宏重定义警告
解决: 检查Config.h中是否有重复定义，注释掉重复的宏定义
```

#### 2. 硬件连接问题
```bash
问题: 传感器初始化失败
解决: 
1. 检查电源连接（3.3V/5V）
2. 检查I2C上拉电阻
3. 确认传感器地址设置
4. 使用万用表测试连接

问题: I2C设备冲突
解决:
1. 使用I2C扫描程序检测设备地址
2. 修改冲突设备的地址
3. 检查SDA/SCL连接
```

#### 3. 网络连接问题
```bash
问题: WiFi连接失败
解决:
1. 检查SSID和密码设置
2. 确认WiFi信号强度
3. 检查路由器MAC地址过滤
4. 尝试使用静态IP

问题: MQTT连接失败
解决:
1. 检查MQTT服务器地址和端口
2. 验证用户名密码
3. 检查防火墙设置
4. 测试MQTT服务器可达性
```

#### 4. 数据异常问题
```bash
问题: 传感器数据不稳定
解决:
1. 启用数据滤波功能
2. 调整滤波参数
3. 检查传感器安装环境
4. 增加读取间隔

问题: 数据验证失败
解决:
1. 检查传感器校准
2. 调整数据有效范围
3. 检查传感器工作环境
4. 更换传感器模块
```

```cpp
// 通过MQTT发送调试信息
void publishDebugInfo() {
    JsonDocument doc;
    doc["heap"] = ESP.getFreeHeap();
    doc["uptime"] = millis();
    doc["wifi_rssi"] = WiFi.RSSI();
    
    String debugInfo;
    serializeJson(doc, debugInfo);
    mqttClient.publish("esp32/debug", debugInfo.c_str());
}
```

## 📊 性能优化建议

### 1. 内存优化

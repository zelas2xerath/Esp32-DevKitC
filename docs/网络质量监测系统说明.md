# 网络质量监测系统说明

## 功能概述

网络质量监测系统是ESP32土壤监测系统的一项新特性，用于实时监测网络连接质量并在异常情况下发出警报。该系统集成了以下功能：

1. **实时网络质量监测**：定期检测WiFi信号强度、网络延迟和丢包率
2. **多维度质量评估**：综合评估网络质量，生成0-100分的质量评分
3. **系统状态集成**：将网络质量状态集成到系统整体状态管理中
4. **自动警报机制**：在网络质量较差时自动发出警报
5. **命令查询接口**：通过指令可随时查询当前网络质量状态

## 网络质量评估指标

系统使用以下指标评估网络质量：

1. **信号强度 (RSSI)**：测量WiFi信号强度，单位dBm
   - 优秀 (> -50 dBm)
   - 良好 (-50 到 -60 dBm)
   - 一般 (-60 到 -70 dBm)
   - 较弱 (-70 到 -80 dBm)
   - 很差 (< -80 dBm)

2. **网络延迟**：测量与服务器通信的往返时间，单位ms
   - 优秀 (< 50 ms)
   - 良好 (50-100 ms)
   - 一般 (100-200 ms)
   - 较差 (200-300 ms)
   - 很差 (> 300 ms)

3. **丢包率**：测量网络通信中的丢包率，单位%
   - 优秀 (< 1%)
   - 良好 (1-5%)
   - 一般 (5-10%)
   - 较差 (10-20%)
   - 很差 (> 20%)

## 质量评分计算

系统综合考虑以上三个指标，计算出一个0-100分的网络质量评分：

- **信号强度评分**：最高40分
  - > -50 dBm：40分
  - -50 到 -60 dBm：32分
  - -60 到 -70 dBm：24分
  - -70 到 -80 dBm：16分
  - -80 到 -90 dBm：8分
  - < -90 dBm：0分

- **丢包率评分**：最高30分
  - 评分 = 30 * (1 - 丢包率/100)

- **延迟评分**：最高30分
  - < 50 ms：30分
  - 50-100 ms：24分
  - 100-200 ms：18分
  - 200-300 ms：12分
  - 300-500 ms：6分
  - > 500 ms：0分

## 系统状态影响

网络质量评分会影响系统状态：

- **< 30分**：系统状态设置为WARNING，显示网络质量警告
- **30-50分**：记录警告日志，但不改变系统状态
- **> 50分**：正常，不影响系统状态

## 使用方法

### 自动监测

系统会每5分钟自动检查一次网络质量，并在质量较差时发出警告。无需手动干预。

### 手动查询

可以通过以下方式手动查询网络质量：

1. **命令查询**：向系统发送`NET_QUALITY`命令
2. **系统管理器API**：调用`systemManager->checkNetworkQuality()`和`systemManager->showNetworkQuality()`方法

### 查看网络质量信息

可以通过以下方式查看网络质量信息：

1. **OLED显示**：发送`NET_QUALITY`命令后，系统会在OLED屏幕上显示网络质量信息
2. **JSON数据**：通过`systemManager->getNetworkQualityJson()`方法获取JSON格式的网络质量数据
3. **日志信息**：系统会在日志中记录网络质量检查结果

## 技术实现

### 核心类和方法

- **NetworkQuality结构体**：定义网络质量相关的数据结构和评估方法
- **NetworkManager类**：实现网络质量监测的核心功能
  - `checkNetworkQuality()`：检查网络质量
  - `measureSignalStrength()`：测量信号强度
  - `measureLatency()`：测量网络延迟
  - `measurePacketLoss()`：测量丢包率
  - `getNetworkQualityJson()`：获取JSON格式的网络质量数据
- **SystemManager类**：集成网络质量管理
  - `checkNetworkQuality()`：检查网络质量
  - `showNetworkQuality()`：显示网络质量信息
  - `evaluateNetworkQuality()`：评估网络质量对系统的影响
- **NetworkQualityHandler类**：处理网络质量查询命令

### 命令处理

系统支持`NET_QUALITY`命令，用于查询网络质量。命令处理流程如下：

1. 收到`NET_QUALITY`命令
2. 调用`systemManager->checkNetworkQuality()`检查网络质量
3. 获取网络质量JSON数据
4. 发送`NET_QUALITY-{json数据}`响应
5. 在OLED上显示网络质量信息

## 配置参数

网络质量监测系统的参数可以通过以下方式配置：

- **检查间隔**：在`SystemManager::loop()`方法中修改`lastNetworkQualityCheck`的间隔时间（默认300000ms，即5分钟）
- **评分阈值**：在`SystemManager::evaluateNetworkQuality()`方法中修改质量评分阈值（默认30分和50分）
